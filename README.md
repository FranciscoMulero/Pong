# Neon Pong

Juego Pong arcade en HTML, CSS y JavaScript.

El modo contra CPU funciona como sitio estático.
El modo online requiere el servidor Node.js incluido.

## Jugar localmente

Abre el enlace de GitHub Page para que se ejecute el fichero index.html en el navegador para jugar contra la CPU.
